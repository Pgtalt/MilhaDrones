# MilhaDrones
Trabalho de Análise de Dados com base em dados de entrega de última milha com drones.

Conjunto de dados foi criado como parte do projeto E-Laas (Energy optimal urban logistics As A Service – Logística urbana energeticamente ótima como serviço). 

Os dados usados neste projeto referente aos arquivos como **Data.xlsx** e **Results.xlsx** para análise de dados e criação de gráficos neste derivam do conjunto de dados publicado no Zenodo sob a licença de domínio público **Creative Commons Zero (CC0)**

DOI do conjunto de dados original, link de acesso público: https://doi.org/10.5281/zenodo.20491777.
